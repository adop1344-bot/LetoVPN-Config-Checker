# LetoVPN Config Checker v1.3

Android-приложение для проверки бесплатных VLESS/xray конфигов.

## Возможности
- 4 метода проверки: Неточная (Молния), Средняя (Баланс), Точная (Радар), Суперточная (Снайпер)
- Тёмная / Светлая / Пользовательская / Динамическая (Android 12+) тема
- Свои источники (добавление URL)
- Многопоточность до 100 потоков
- 0 конфигов в слайдере = проверить все
- Копирование каждого конфига отдельно + топ-10
- Сохранение рабочих в TXT
- Плавные анимации списка
- Telegram: @letovpn_free

## Сборка
APK автоматически собирается в GitHub Actions → Artifacts.
