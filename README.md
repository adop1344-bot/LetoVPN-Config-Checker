# LetoVPN Config Checker

Android-приложение для проверки бесплатных VLESS/xray конфигов.

Источники берутся из: [LetoVPN_free/sources.txt](https://github.com/adop1344-bot/LetoVPN_free)

## Возможности
- Красивый Material Design 3 интерфейс
- 2 режима проверки: TCP и Via Proxy GET
- Выбор количества конфигов для проверки
- Сохранение всех рабочих конфигов в TXT
- Копирование топ-10 по скорости
- Ссылка на Telegram-канал @letovpn_free

## Сборка APK
Автоматическая через GitHub Actions → Releases
