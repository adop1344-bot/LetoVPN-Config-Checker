# Changelog — LetoVPN Config Checker

## [1.6] — 2026-08-08

### Добавлено
- Включение/выключение источников (включая системный `sources.txt`)
- Метод **Максимум (Xray Speed)** — проверка через Xray с реальной загрузкой ~100 KB
- Опция «Стоп после N рабочих конфигов»
- Фильтр «Только VLESS»
- Экспорт:
  - TXT-файл
  - подписка в base64 (буфер обмена)
  - топ-10 конфигов
- Меню сохранения по кнопке 💾
- Долгое нажатие на 📋 — сразу base64-подписка
- Отображение версии в настройках

### Изменено
- Системный и пользовательские источники управляются переключателями
- Для Xray/Xray Speed ограничена многопоточность (стабильность)

---

## [1.5] — 2026-08-08

### Добавлено
- Метод **Xray (ядро)** — автоскачивание Xray-core под ABI устройства
- Реальная проверка VLESS через локальный SOCKS-прокси
- Автосохранение настроек при выходе из экрана
- Новый класс `Prefs` (фикс сброса настроек / бага StringSet)

### Изменено
- Полностью переработан главный экран (header, круглые кнопки)
- Тема применяется корректно после сохранения

### Исправлено
- Настройки больше не сбрасывались из‑за SharedPreferences

---

## [1.4] — 2026-08-08

### Добавлено
- 4 реальных метода проверки:
  - Неточная (TCP)
  - Средняя (TCP+DNS)
  - Точная (Via Proxy GET)
  - Суперточная (Deep)
- Темы: тёмная / светлая / пользовательская / динамическая (Android 12+)
- Свои источники (URL)
- Лимит потоков до 100
- Количество конфигов: `0` = проверить все

### Изменено
- Убраны «фейковые» методы (Молния/Снайпер и т.п.)
